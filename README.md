# BUZZ/1.0 Quiz Buzzer Protocol

Network application สำหรับจำลองระบบ **กดออดตอบคำถามแบบเรียลไทม์** โดยมีผู้เล่นหลายคนแข่งขันกันกด Buzz เพื่อชิงสิทธิ์ตอบคำถาม และมี Host เป็นผู้ควบคุมเกมและตัดสินคำตอบ
